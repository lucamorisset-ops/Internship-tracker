Configuration à terminer

La clé publique de Supabase n'est pas encore renseignée dans site/config.js.

  1. Dans Supabase : Project Settings › API Keys, copie la Publishable key (elle commence par sb_publishable_).
  2. Dans le dépôt GitHub, ouvre site/config.js et remplace REMPLACER_PAR_LA_PUBLISHABLE_KEY par cette clé, puis enregistre (commit). Cette clé est publique par conception : les données restent protégées par les règles d'accès (RLS).
  3. Dans Supabase : Authentication › URL Configuration, mets l'adresse du site () dans Site URL et dans Redirect URLs, sinon le lien de connexion ne ramènera pas ici.
  4. Vérifie que ton adresse e-mail figure dans la table allowed_users.

Ne colle jamais la clé secrète (sb_secret_…) dans ce fichier : elle reste dans les secrets GitHub du robot. Pour voir le site avec des données fictives, ajoute ?demo=1 à l'adresse.

Plus lent, mais ton ordi n'a pas besoin d'être allumé. Si le site montre une page anti-robot, le robot s'arrête et le site apparaît ci-dessous.
